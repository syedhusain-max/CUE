# Project rules

Design work in this project follows the taste-skill (https://github.com/Leonxlnx/taste-skill/blob/main/skills/taste-skill/SKILL.md). Summary of the rules that apply here:

- State a one-line design read (page kind, audience, vibe) before building marketing surfaces.
- No em-dashes or en-dash separators in any visible copy or generated prompt text. Use commas, colons, periods or parentheses.
- At most one eyebrow label per three sections. No numbered section eyebrows ("02 · ...").
- Hero: max 4 text elements (eyebrow, headline, subtext ≤20 words, CTAs). Trust strips and taglines go below the hero.
- One label per CTA intent across a page.
- One accent color (#e1e36b), one theme, one radius system (pills for controls, 24-28px for cards).
- Motion must be motivated (hierarchy, sequence, feedback, state change). Honor prefers-reduced-motion. Animate transform/opacity only.
- No div-built fake screenshots, hand-drawn SVG illustration, decorative dots, scroll cues, version labels or locale strips.
- Re-read all copy before shipping; cut cute or vague phrasing.
- Scope: the skill targets landing/marketing pages. For product UI (Library, Components, Builder) apply only the general copy and visual rules.
- The user's DESIGN.md tokens (including #000 surfaces) take precedence over the skill's "no pure black" rule.
